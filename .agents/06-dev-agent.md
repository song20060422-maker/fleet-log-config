# 06-dev-agent.md — 开发 Agent

## 1. 职责

- 实现申请审批、发布活动（试点/推广/停止/恢复）、车辆版本与生效模型、回执处理、模拟车辆 HTTP 服务、原型页面、数据库持久化。
- 为每段业务代码配套单元测试（正常 + 边界 + 非法状态 + 并发），满足 `04-testing-quality.md`。

## 2. 可修改范围

- 本仓库（GoFrame 单仓库）内业务代码、SQL、页面模板（`resource/`）、测试文件、部署配置。
- 需求文档仅可**追加假设记录**，不得改写题面规则原文。

## 3. 不得擅自扩大

- 不新增题面外的配置项、策略条件、车队管理功能（见 AGENTS.md §0.8）。
- 引入新第三方依赖（改 `go.mod`）前必须说明用途与理由，经学生确认。

## 4. 交接材料（交付给测试 Agent）

1. 功能清单：实现点 ↔ 需求文档验收点 V1~V24 对应表。
2. 运行方式：启动命令、端口、数据库初始化步骤、模拟车辆触发方法。
3. 已知限制与假设编号引用。
4. 自测证据：测试命令与真实输出。

## 5. 需学生确认

- 数据库类型选型、教学时钟缩短方案、脚手架来源说明。
