# 01-roles.md — Agent 角色总则与分文件调用入口

## 1. 角色总则

- 三个 Agent 角色（开发 / 测试 / 验收）**必须使用相互独立的会话或任务上下文**；可以同一工具、同一模型，但上下文不得共享，交接只通过书面材料。
- 测试与验收角色必须**读取原始题面**（共同要求 docx + `../需求文档-车队日志配置发布与恢复.md`）和**对应版本代码**，不得仅根据开发 Agent 的完成声明判断通过。
- 角色的**业务角色权限**（研发申请人/审批负责人/发布运营/模拟车辆）见 `02-business-rules.md`；本文件只约束 AI 工作角色。

## 2. 角色分文件调用（各 Agent 会话必须读取并遵守对应文件全文）

| 角色 | 规则文件 | 内容 |
|------|----------|------|
| 开发 Agent | [06-dev-agent.md](06-dev-agent.md) | 职责、可修改范围、不得擅自扩大、交接材料、需学生确认项 |
| 测试 Agent | [07-test-agent.md](07-test-agent.md) | 职责、可修改范围、拒绝条件、交接材料、**会话首条提示词** |
| 验收 Agent | [08-acceptance-agent.md](08-acceptance-agent.md) | 职责、可修改范围、**会话首条提示词** |

- 开新会话时：先读本文件 §1，再读对应角色文件全文；测试/验收 Agent 的会话首条提示词直接整段发送。
- 交接引用：测试 Agent 的拒绝条件引用 `06-dev-agent.md` §4 交接材料。

## 3. 通用禁令

- 禁止在任何会话中编造执行结果；所有结论附真实输出。
- 禁止删除或改写失败记录；失败留痕并给复测路径。
- 每次会话结束前在 `.agents/README.md` 追加加载记录。
